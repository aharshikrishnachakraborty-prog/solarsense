How do we know it works?

  1. The dataset has no official list of faults, so we created our own: we took healthy days from the test period and broke them on purpose — switched inverters off, cut their output, removed readings, added slow dust-like decline.
  2. We then ran exactly the same detector, with the same thresholds, and checked which of our planted faults it found.
  3. Because we know exactly where every planted fault is, we can count what it catches, what it misses and when it raises false alarms — including the faults it is bad at.
